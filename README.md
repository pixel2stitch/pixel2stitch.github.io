## 📱 About the Project

**pixel2stitch** is an iOS app that lets you:

- Convert photos into detailed embroidery patterns
- Use official DMC, Anchor, Gamma, and other brand palettes
- Export patterns to PDF
- Sync projects via iCloud
- Ready-Made Pattern Library

This repository contains the **single-page landing site** for the app.

---

## 🧩 Tech Stack

- **HTML5** — semantic markup
- **CSS3** — responsive design, light/dark theme support
- **JavaScript (Vanilla)** — no external libraries
- **GitHub Pages** — hosting
- **JSON** — localization (Russian / English)

---

## 🌐 Language Support

- Russian (automatic for users with browser language set to `ru`)
- English (fallback for all other users)

---

## 🎨 Key Features

- **Responsive design** — works on all screen sizes
- **Light / Dark / System theme** — user preference saved in `localStorage`
- **Parallax effect** on main screenshots
- **Horizontal carousel** with vertical iPhone screenshots
- **Live localization** without page reload
- **"Back to Top" button** with smooth scrolling
- **Open Graph & Twitter Cards** for beautiful social media previews
